# Fake-Job-Posting-Detection-ANN

This project detects whether a job posting is real or fake using a neural network.

## What I used
- ANN (Artificial Neural Network) — Binary Classification
- Python, TensorFlow/Keras, NLP (text processing)

## What the model does
- Takes job posting text/details
- Predicts: Real Job (0) or Fake Job (1)

## Files
- `Fake_Job_Posting_Detection_ANN.ipynb` → main notebook with all code

## How to run
1. Download the notebook
2. Open in Jupyter or Google Colab
3. Run all cells from top to bottom
